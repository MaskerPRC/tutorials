在 C++中加载 TorchScript 模型 ¶


创建时间：2025年4月1日 | 最后更新时间：2025年4月1日 | 最后验证时间：2024年11月5日

警告

TorchScript 不再处于活跃开发状态。

正如其名所示，PyTorch 的主要接口是 Python 编程语言。虽然 Python 对于需要动态性和迭代易用性的许多场景来说是一个合适且首选的语言，但在许多情况下，Python 的这些特性并不理想。后者经常适用的一个环境是生产 ——低延迟和严格的部署要求之地。对于生产场景，C++通常是首选的语言，即使只是为了将其绑定到 Java、Rust 或 Go 等其他语言。以下段落将概述 PyTorch 从现有的 Python 模型到可以无依赖 Python 纯从 C++ 加载和执行的序列化表示的路径。

步骤 1：将您的 PyTorch 模型转换为 Torch Script¶

PyTorch 模型的从 Python 到 C++的旅程由 Torch Script 实现，这是 PyTorch 模型的一种表示形式，可以被 Torch Script 编译器理解、编译和序列化。如果您是从现有的使用纯“eager”API 编写的 PyTorch 模型开始，您必须首先将您的模型转换为 Torch Script。在以下讨论的常见情况下，这只需要很少的努力。如果您已经有了 Torch Script 模块，您可以跳到本教程的下一部分。

将 PyTorch 模型转换为 Torch Script 有两种方法。第一种被称为跟踪 ，这是一种通过使用示例输入评估模型一次，并记录这些输入在模型中的流动结构的机制。这适用于使用控制流有限度的模型。第二种方法是在您的模型中添加显式的注释，告知 Torch Script 编译器它可以直接解析和编译您的模型代码，前提是遵守 Torch Script 语言施加的约束。

提示


您可以在官方 PyTorch 脚本文档中找到这两种方法的完整文档，以及关于如何选择使用的进一步指导。 参考 。

通过 Tracing 转换为 Torch Script¶


要通过 Tracing 将 PyTorch 模型转换为 Torch Script，您必须传递一个模型实例以及一个示例输入到 torch.jit.trace 函数。这将生成一个 torch.jit.ScriptModule 对象，其中包含模型评估的跟踪嵌入到模块的 forward 方法中：

import torch
import torchvision

# An instance of your model.
model = torchvision.models.resnet18()

# An example input you would normally provide to your model's forward() method.
example = torch.rand(1, 3, 224, 224)

# Use torch.jit.trace to generate a torch.jit.ScriptModule via tracing.
traced_script_module = torch.jit.trace(model, example)

跟踪的 ScriptModule 现在可以像常规 PyTorch 模块一样进行评估：

In[1]: output = traced_script_module(torch.ones(1, 3, 224, 224))
In[2]: output[0, :5]
Out[2]: tensor([-0.2698, -0.0381,  0.4023, -0.3010, -0.0448], grad_fn=<SliceBackward>)

通过注解转换为 Torch Script¶

在某些情况下，例如如果您的模型使用特定的控制流形式，您可能希望直接在 Torch Script 中编写模型并相应地注解模型。例如，假设您有一个以下纯 PyTorch 模型：

import torch

class MyModule(torch.nn.Module):
    def __init__(self, N, M):
        super(MyModule, self).__init__()
        self.weight = torch.nn.Parameter(torch.rand(N, M))

    def forward(self, input):
        if input.sum() > 0:
          output = self.weight.mv(input)
        else:
          output = self.weight + input
        return output

因为这个模块的 forward 方法使用了依赖于输入的控制流，所以它不适合进行追踪。相反，我们可以将其转换为 ScriptModule。为了将模块转换为 ScriptModule，需要使用 torch.jit.script 编译模块，如下所示：

class MyModule(torch.nn.Module):
    def __init__(self, N, M):
        super(MyModule, self).__init__()
        self.weight = torch.nn.Parameter(torch.rand(N, M))

    def forward(self, input):
        if input.sum() > 0:
          output = self.weight.mv(input)
        else:
          output = self.weight + input
        return output

my_module = MyModule(10,20)
sm = torch.jit.script(my_module)


如果您需要排除您的 nn.Module 中的某些方法 因为它们使用了 TorchScript 尚不支持的一些 Python 特性， 您可以使用 @torch.jit.ignore 对这些方法进行注释


sm 是一个实例 ScriptModule 已准备好进行序列化

步骤 2：将您的脚本模块序列化到文件 ¶


一旦您手中有了 ScriptModule，无论是从追踪还是注释 PyTorch 模型中获得的，您就可以将其序列化到文件中。稍后，您可以从该文件中加载模块并在 C++ 中执行它，而无需依赖 Python。假设我们想要序列化如上所示的 ResNet18 模型 在追踪示例中较早的示例。要执行此序列化，只需调用 保存 在模块上，并传递一个文件名：

traced_script_module.save("traced_resnet_model.pt")


这将在您的当前工作目录中生成一个 traced_resnet_model.pt 文件。如果您还想序列化 sm，请调用 sm.save("my_module_model.pt") 我们现在已经正式离开了 Python 的领域，准备进入 C++的领域 的世界。

第 3 步：在 C++中加载您的脚本模块 ¶

要在 C++中加载您的序列化 PyTorch 模型，您的应用程序必须依赖于 PyTorch C++ API，也称为 LibTorch。LibTorch 发行版包含一系列共享库、头文件和 CMake 构建配置文件。虽然 CMake 不是依赖 LibTorch 的必要条件，但它是一种推荐的方法，并且在未来将得到良好的支持。在本教程中，我们将使用 CMake 和 LibTorch 构建一个最小的 C++应用程序，该应用程序简单地加载并执行一个序列化的 PyTorch 模型。

一个简单的 C++应用程序 ¶

让我们先讨论加载模块的代码。以下代码已经可以做到：

#include <torch/script.h> // One-stop header.

#include <iostream>
#include <memory>

int main(int argc, const char* argv[]) {
  if (argc != 2) {
    std::cerr << "usage: example-app <path-to-exported-script-module>\n";
    return -1;
  }


  torch::jit::script::Module module;
  try {
    // Deserialize the ScriptModule from a file using torch::jit::load().
    module = torch::jit::load(argv[1]);
  }
  catch (const c10::Error& e) {
    std::cerr << "error loading the model\n";
    return -1;
  }

  std::cout << "ok\n";
}


《torch/script.h》 头文件包含了运行示例所需的 LibTorch 库中所有相关的包含文件。我们的应用程序接受一个序列化的 PyTorch ScriptModule 文件的路径作为其唯一的命令行参数，然后使用 torch::jit::load() 函数，该函数接受这个文件路径作为输入。作为回报，我们收到一个 torch::jit::script::Module 对象。我们将在稍后考察其执行方式。

根据 LibTorch 和构建应用程序 ¶

假设我们将上述代码存储到一个名为 example-app.cpp 的文件中。构建它的最小 CMakeLists.txt 可能会像这样简单：

cmake_minimum_required(VERSION 3.0 FATAL_ERROR)
project(custom_ops)

find_package(Torch REQUIRED)

add_executable(example-app example-app.cpp)
target_link_libraries(example-app "${TORCH_LIBRARIES}")
set_property(TARGET example-app PROPERTY CXX_STANDARD 17)


构建示例应用程序的最后一步是获取 LibTorch 发行版。您始终可以从 下载 获取最新的稳定版本。 PyTorch 网站上的页面 。如果您下载并解压最新存档，应该会收到一个包含以下目录结构的文件夹：

libtorch/
  bin/
  include/
  lib/
  share/

  • lib/ 文件夹包含您必须链接的共享库，

  • include/ 文件夹包含您的程序需要包含的头文件，

  • share/ 文件夹包含必要的 CMake 配置，以启用上面的简单 find_package(Torch) 命令。

提示


在 Windows 上，调试和发布版本不兼容 ABI。如果您计划以调试模式构建项目，请尝试 LibTorch 的调试版本。同时，请确保在 cmake --build . 中指定正确的配置。 以下行。

最后一步是构建应用程序。为此，假设我们的示例目录布局如下：

example-app/
  CMakeLists.txt
  example-app.cpp

步骤 4：在 C++ 中执行脚本模块 ¶

成功加载我们的序列化 ResNet18 到 C++ 中后，我们现在只需几行代码就可以执行它了！让我们将这些行添加到我们的 C++ 应用程序的 main() 函数中：

// Create a vector of inputs.
std::vector<torch::jit::IValue> inputs;
inputs.push_back(torch::ones({1, 3, 224, 224}));

// Execute the model and turn its output into a tensor.
at::Tensor output = module.forward(inputs).toTensor();
std::cout << output.slice(/*dim=*/1, /*start=*/0, /*end=*/5) << '\n';


前两行设置模型输入。我们创建一个向量 torch::jit::IValue（一种类型擦除的值类型 script::Module 方法） 接受并返回，并添加一个单独的输入。要创建输入张量，我们使用 torch::ones()，它是 C++ API 中 torch.ones 的等效函数。然后我们运行 script::Module 的 forward 方法，将我们创建的输入向量传递给它。作为回报，我们得到一个新的 IValue，通过调用 toTensor() 将其转换为张量。 要了解更多关于 torch::ones 等函数以及 PyTorch C++ API 的信息，请参阅其文档 https://pytorch.org/cppdocs。PyTorch C++ API 提供了与 Python API 几乎相同的功能，允许您像在 Python 中一样进一步操作和处理张量。

提示

torch::ones 等函数和 PyTorch C++ API 的更多信息，请参阅其文档 https://pytorch.org/cppdocs。PyTorch C++ API 提供了与 Python API 几乎相同的功能，允许您像在 Python 中一样进一步操作和处理张量。

步骤 5：获取帮助和探索 API¶

这篇教程可能已经让您对 PyTorch 模型从 Python 到 C++ 的路径有了基本的了解。通过本教程中描述的概念，您应该能够从原始的、“急切”的 PyTorch 模型，编译成 Python 中的 ScriptModule，到磁盘上的序列化文件，再到闭合循环的 C++ 中的可执行 script::Module。


当然，我们还没有涵盖许多概念。例如，您可能会发现自己想要扩展您的 ScriptModule，以实现一个在 C++ 或 CUDA 中实现的自定义操作符 并在您的程序中执行这个自定义操作符 在您的纯 C++生产环境中加载了 ScriptModule。好消息是：这是可能的，并且得到了良好的支持！目前，您可以探索 这个 文件夹中的示例，我们很快会提供教程。在此期间，以下链接可能普遍有帮助：

  • PyTorch C++ API 文档： https://pytorch.org/cppdocs/

  • PyTorch Python API 文档： https://pytorch.org/docs/
