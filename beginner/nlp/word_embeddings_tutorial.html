词嵌入：编码词汇语义 ¶


创建于：2025 年 4 月 1 日 | 最后更新：2025 年 4 月 1 日 | 最后验证：2024 年 11 月 5 日

词嵌入是词汇中每个词的真实数值密集向量。在 NLP 中，几乎总是你的特征是单词！但是你应该如何在计算机中表示一个单词呢？你可以存储它的 ascii 字符表示，但这只能告诉你这个词是什么，并不能告诉你它代表什么（你可能可以从它的词缀中推导出它的词性，或者从它的首字母大写中获取属性，但并不多）。更进一步，你如何将这些表示组合起来？我们通常希望从我们的神经网络中得到密集的输出，其中输入是 \(|V|\) 维，其中 \(V\) 是我们的词汇，但通常输出只有几个维度（如果我们只预测几个标签，例如）。我们如何从一个巨大的维度空间转换到一个较小的维度空间？

那么我们为什么不使用 ascii 表示，而是使用 one-hot 编码呢？也就是说，我们通过以下方式表示单词 \(w\)：

\[\overbrace{\left[ 0, 0, \dots, 1, \dots, 0, 0 \right]}^\text{|V| elements} \]

其中 1 的位置是唯一的\(w\)。其他任何单词都将有一个 1 在某个其他位置，其他位置都是 0。

除了它非常庞大之外，这种表示方法还有一个巨大的缺点。它基本上将所有单词视为相互独立的实体，没有任何关系。我们真正想要的是单词之间相似性的概念。为什么？让我们看一个例子。

假设我们正在构建一个语言模型。假设我们看到了以下句子

  • 这位数学家跑到商店去了。

  • 这位物理学家跑到商店去了。

  • 这位数学家解决了这个公开问题。

在我们的训练数据中。现在假设我们得到了一个在训练数据中从未见过的新的句子：

  • 物理学家解决了这个公开问题。

我们的语言模型可能在这句话上做得不错，但如果我们能使用以下两个事实会更好：

  • 我们已经看到数学家和物理学家在句子中扮演相同的角色。他们似乎有语义关系。

  • 我们已经看到数学家在这个新未见过的句子中扮演与我们现在看到的物理学家相同的角色。

然后推断物理学家在新未见句子中实际上是一个很好的匹配吗？这就是我们所说的相似性概念：我们所说的相似性是指语义相似性，而不仅仅是具有相似的书写形式。这是一种对抗语言数据稀疏性的技术，通过在我们已经看到和尚未看到的事物之间建立联系。当然，这个例子依赖于一个基本的语言假设：出现在相似上下文中的词语在语义上是相关的。这被称为分布假设。

获取密集词嵌入

我们如何解决这个问题？也就是说，我们如何实际上编码词语的语义相似性？也许我们可以想出一些语义属性。例如，我们看到数学家和物理学家都能跑步，所以我们可能给这些词语“能够跑步”的语义属性一个高分。想想其他的属性，并想象你可能会在这些属性上对一些常见词语进行评分。

如果每个属性都是一个维度，那么我们可能给每个词一个向量，就像这样：

\[ q_\text{数学家} = \left[ \overbrace{2.3}^\text{能跑}, \overbrace{9.4}^\text{喜欢咖啡}, \overbrace{-5.5}^\text{主修物理}, \dots \right]\]
\[ q_\text{物理学家} = \left[ \overbrace{2.5}^\text{能跑}, \overbrace{9.1}^\text{喜欢咖啡}, \overbrace{6.4}^\text{主修物理}, \dots \right]\]

然后，我们可以通过以下方式得到这些词之间的相似度度量：

\[\text{相似度}(\text{物理学家}, \text{数学家}) = q_\text{物理学家} \cdot q_\text{数学家} \]

虽然按长度归一化更为常见：

\[ \text{相似度}(\text{物理学家}, \text{数学家}) = \frac{q_\text{物理学家} \cdot q_\text{数学家}} {\| q_\text{物理学家} \| \| q_\text{数学家} \|} = \cos (\phi)\]

其中 \(\phi\) 是两个向量之间的角度。这样，极其相似的词（词嵌入指向同一方向）将具有相似度 1。极其不相似的词应该具有相似度 -1。

您可以将本节开头的稀疏独热向量视为我们定义的新向量的一个特例，其中每个词基本上具有相似度 0，并且我们为每个词赋予了一些独特的语义属性。这些新向量是密集的，也就是说它们的条目（通常是）非零。

但是这些新向量是个大麻烦：你可能想到成千上万种可能相关的语义属性，用以确定相似性，你究竟该如何设置不同属性的价值呢？深度学习的核心思想是神经网络学习特征的表示，而不是要求程序员自己设计。那么为什么不直接让词嵌入成为我们模型中的参数，然后在训练过程中更新它们呢？这正是我们将要做的。我们将有一些潜在语义属性，网络原则上可以学习。请注意，词嵌入可能不可解释。也就是说，尽管我们可以通过上面手工制作的向量看到数学家和物理学家在喜欢咖啡这一点上是相似的，如果我们允许神经网络学习嵌入并看到数学家和物理学家在第二个维度上都有较大的值，这并不清楚这意味着什么。他们在某些潜在语义维度上是相似的，但这可能对我们没有解释意义。

总结来说，词嵌入是单词的*语义*表示，有效地编码与当前任务相关的语义信息。你还可以嵌入其他内容：词性标签、句法树，等等！特征嵌入的概念是该领域的核心。

Pytorch 中的词嵌入

在我们进入工作示例和练习之前，关于如何在 Pytorch 和深度学习编程中一般使用嵌入的一些简要说明。类似于我们在制作独热向量时为每个单词定义一个唯一索引，在使用嵌入时，我们也需要为每个单词定义一个索引。这些将成为查找表的键。也就是说，嵌入存储为一个 \(|V| \times D\) 矩阵，其中 \(D\) 是嵌入的维度，使得分配索引 \(i\) 的单词的嵌入存储在矩阵的第 \(i\) 行。在我的所有代码中，从单词到索引的映射是一个名为 word_to_ix 的字典。

允许你使用嵌入的模块是 torch.nn.Embedding，它接受两个参数：词汇大小和嵌入的维度。

要索引此表，您必须使用 torch.LongTensor（因为索引是整数，不是浮点数）。

# Author: Robert Guthrie

import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim

torch.manual_seed(1)

word_to_ix = {"hello": 0, "world": 1}
embeds = nn.Embedding(2, 5)  # 2 words in vocab, 5 dimensional embeddings
lookup_tensor = torch.tensor([word_to_ix["hello"]], dtype=torch.long)
hello_embed = embeds(lookup_tensor)
print(hello_embed)

示例：N-gram 语言模型

回想一下，在 n-gram 语言模型中，给定一个单词序列 \(w\)，我们想要计算

\[P(w_i | w_{i-1}, w_{i-2}, \dots, w_{i-n+1} ) \]

\(w_i\) 是序列的第 i 个词。

在这个例子中，我们将对一些训练示例计算损失函数，并使用反向传播更新参数。

CONTEXT_SIZE = 2
EMBEDDING_DIM = 10
# We will use Shakespeare Sonnet 2
test_sentence = """When forty winters shall besiege thy brow,
And dig deep trenches in thy beauty's field,
Thy youth's proud livery so gazed on now,
Will be a totter'd weed of small worth held:
Then being asked, where all thy beauty lies,
Where all the treasure of thy lusty days;
To say, within thine own deep sunken eyes,
Were an all-eating shame, and thriftless praise.
How much more praise deserv'd thy beauty's use,
If thou couldst answer 'This fair child of mine
Shall sum my count, and make my old excuse,'
Proving his beauty by succession thine!
This were to be new made when thou art old,
And see thy blood warm when thou feel'st it cold.""".split()
# we should tokenize the input, but we will ignore that for now
# build a list of tuples.
# Each tuple is ([ word_i-CONTEXT_SIZE, ..., word_i-1 ], target word)
ngrams = [
    (
        [test_sentence[i - j - 1] for j in range(CONTEXT_SIZE)],
        test_sentence[i]
    )
    for i in range(CONTEXT_SIZE, len(test_sentence))
]
# Print the first 3, just so you can see what they look like.
print(ngrams[:3])

vocab = set(test_sentence)
word_to_ix = {word: i for i, word in enumerate(vocab)}


class NGramLanguageModeler(nn.Module):

    def __init__(self, vocab_size, embedding_dim, context_size):
        super(NGramLanguageModeler, self).__init__()
        self.embeddings = nn.Embedding(vocab_size, embedding_dim)
        self.linear1 = nn.Linear(context_size * embedding_dim, 128)
        self.linear2 = nn.Linear(128, vocab_size)

    def forward(self, inputs):
        embeds = self.embeddings(inputs).view((1, -1))
        out = F.relu(self.linear1(embeds))
        out = self.linear2(out)
        log_probs = F.log_softmax(out, dim=1)
        return log_probs


losses = []
loss_function = nn.NLLLoss()
model = NGramLanguageModeler(len(vocab), EMBEDDING_DIM, CONTEXT_SIZE)
optimizer = optim.SGD(model.parameters(), lr=0.001)

for epoch in range(10):
    total_loss = 0
    for context, target in ngrams:

        # Step 1. Prepare the inputs to be passed to the model (i.e, turn the words
        # into integer indices and wrap them in tensors)
        context_idxs = torch.tensor([word_to_ix[w] for w in context], dtype=torch.long)

        # Step 2. Recall that torch *accumulates* gradients. Before passing in a
        # new instance, you need to zero out the gradients from the old
        # instance
        model.zero_grad()

        # Step 3. Run the forward pass, getting log probabilities over next
        # words
        log_probs = model(context_idxs)

        # Step 4. Compute your loss function. (Again, Torch wants the target
        # word wrapped in a tensor)
        loss = loss_function(log_probs, torch.tensor([word_to_ix[target]], dtype=torch.long))

        # Step 5. Do the backward pass and update the gradient
        loss.backward()
        optimizer.step()

        # Get the Python number from a 1-element Tensor by calling tensor.item()
        total_loss += loss.item()
    losses.append(total_loss)
print(losses)  # The loss decreased every iteration over the training data!

# To get the embedding of a particular word, e.g. "beauty"
print(model.embeddings.weight[word_to_ix["beauty"]])

练习：计算词嵌入：连续词袋模型

连续词袋模型（CBOW）在自然语言处理深度学习中经常被使用。它是一种试图根据目标词前后的一些词的上下文来预测词的模型。这与语言模型不同，因为 CBOW 不是顺序的，也不必是概率性的。通常，CBOW 用于快速训练词嵌入，这些嵌入被用来初始化一些更复杂模型的嵌入。通常，这被称为预训练嵌入。它几乎总是有助于性能提高几个百分点。

CBOW 模型如下。给定目标词\(w_i\)和每侧的\(N\)个上下文窗口，\(w_{i-1}, \dots, w_{i-N}\)和\(w_{i+1}, \dots, w_{i+N}\)，将所有上下文词统称为\(C\)，CBOW 试图最小化

\[-\log p(w_i | C) = -\log \text{Softmax}\left(A(\sum_{w \in C} q_w) + b\right) \]

其中\(q_w\)是词\(w\)的嵌入。

在下面的类中实现此模型。一些提示：

  • 考虑你需要定义哪些参数。

  • 确保你知道每个操作期望的形状。如果你需要重塑，请使用.view()。

CONTEXT_SIZE = 2  # 2 words to the left, 2 to the right
raw_text = """We are about to study the idea of a computational process.
Computational processes are abstract beings that inhabit computers.
As they evolve, processes manipulate other abstract things called data.
The evolution of a process is directed by a pattern of rules
called a program. People create programs to direct processes. In effect,
we conjure the spirits of the computer with our spells.""".split()

# By deriving a set from `raw_text`, we deduplicate the array
vocab = set(raw_text)
vocab_size = len(vocab)

word_to_ix = {word: i for i, word in enumerate(vocab)}
data = []
for i in range(CONTEXT_SIZE, len(raw_text) - CONTEXT_SIZE):
    context = (
        [raw_text[i - j - 1] for j in range(CONTEXT_SIZE)]
        + [raw_text[i + j + 1] for j in range(CONTEXT_SIZE)]
    )
    target = raw_text[i]
    data.append((context, target))
